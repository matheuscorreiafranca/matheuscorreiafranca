# Profile maintenance

This repository is the public GitHub profile for `matheuscorreiafranca`.

## Update checklist

1. Keep professional claims qualitative unless a metric is current, authorized and verifiable.
2. Add a featured project only after its README, description and setup instructions are complete.
3. Keep all SVG assets self-hosted in `assets/` and provide meaningful alt text in `README.md`.
4. Check every external badge and link after changing the stack or contact details.
5. Review the English and Portuguese summaries together so they remain consistent.
6. Never add client names, internal URLs, credentials, business data or proprietary source code.
